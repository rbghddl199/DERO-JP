PROJECT OVERVIEW

製品を購入する前に
仮想空間でレイアウトと組み合わせを
確認し、不要な購入や空間づくりの
試行錯誤を減らします。

先につくってみる、わたしのデスク
実測ベースの3Dデスク環境シミュレーター

買う前に、わたしのデスクを
3Dで先に配置してみよう。

DEROは、実際の製品スペックをもとに自分だけのデスク環境を構成し、製品間の互換性と予算を事前に確認できる3Dデスク環境サービスです。

背景と課題

BACKGROUND

デスク周りの製品は
実際に購入して設置するまで
サイズや配置の適合性を
正確に判断するのが難しい。

PROBLEM

買ってから気づく問題

01
規格の不一致
モニターアームのクランプと天板の厚みなど、設置条件が合わないケース
02
スペース不足
デスク上の空間が足りず、思い通りに配置できないケース
03
全体像が見えない
通販サイトの画像や製品情報だけではデスク全体の姿がわからない
SOLUTION 実際の製品スペックでデスクを事前に構成し、購入前に配置と予算を検討できるサービス
